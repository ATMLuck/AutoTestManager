# Options
####  The input example file path
```bash
-i/--input [file_path]
```
> The default file path is `./in.txt`
#### The output example file path
```bash
-o/--output [file_path]
```
> he default file path is `./out.txt`
#### The input example files directory
```bash
-I/--input-dir [files_dir_path]
```
> The default directory path is `./in/`
> File name corresponds to `output example files directory`
#### The output example files directory
```bash
-O/--output-dir [files_dir_path]
```
> The default direatory path is `./out/`
> File name corresponds to `input example files directory`
#### Use the compiled program directory
```bash
-p/--program [file_path]
```
#### The source file path
```bash
-c/--complied [file_path]
```
> The "-c/--complied" option can be omitted when it is the first parameter.
#### The complied program output path
```bash
-b/--build [file_path]
```
> The default path is `./build/`
#### Enable and set the running time limit
```bash
-t/--time [time(ms)]
```
> The default time is `1000ms`
#### Enable and set the running space limit
```bash
-s/--space [space(KB)]
```
